# 边学 Haskell 边学范畴论

从可运行的代码倒推范畴论：函子、应用函子、单子，以及它们的工程落地。

**在线阅读：<https://freakwill.github.io/haskell-category/>**

## 这本书想解决什么

你能写 Python，也听说过 monad，看过几篇讲范畴论的博客，但这两件事在脑子里始终是分开的。
本书的写法是**从能跑的程序倒推数学**：每章先有一个跑不起来、或者写起来极其难看的程序，
再由它逼出一个概念。

## 目录结构

```
src/            正文（mdBook 源，一章一文件）
code/           Haskell 工程：全书代码的唯一可编译真源
snippets/       从 2019 年草稿自动抽出的代码片段与体检报告
tools/          抽取、体检、脚手架脚本
Haskell.md      2019 年原始草稿，冻结只读，不再改动
site/           mdBook 构建输出（不入库）
```

**正文不手抄代码。** 书里的每段 Haskell 都在 `code/` 里，用 `ANCHOR` 标记切分，
正文用 `{{#include ../../code/src/Ch07/Basics.hs:anchor}}` 引入。改代码必须走工程，
工程必须过测试——这样书里不会出现跑不通的代码。

## 本地构建

```bash
# 站点（需要 mdbook 0.4.52）
mdbook build && open site/index.html   # 或 mdbook serve

# 代码
export PATH="$HOME/.ghcup/bin:$PATH"
cd code && cabal build all && cabal test all
```

## 约定

- 每章六段式：问题 → 数学 → 代码 → 陷阱 → 练习（A 改写 / B 证明 / C 造实例）→ 延伸。
- 数学证明标 ◇，可跳过；完整推导进附录 A。
- 术语首次出现给英文原文，统一记在附录 C。
- 版本：GHC 9.14 / cabal 3.18。
