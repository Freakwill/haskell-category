# 断言清单

各章的实体断言抽成表，供审读用。本目录不进书，也不参与站点构建。

## 为什么有这张表

正文的说法分三类，可信度来源不同：

- **S（符号推演）**：从定义出发，两边化简到同一个式子。写不出这一步的，不应写成肯定句。
- **C（代码或运行）**：有可执行的真值——`hspec` 断言、`runghc` 的输出、`ghc` 的报错原文。
- **T（底本）**：定义与定理的名称、条件、归属，对到具体书的节号。没对上的，只能写成"据某书"。

## 状态

| 标记 | 含义 |
|---|---|
| ✓ | 已核，依据写在"核验"列 |
| ✗ | 有误，修法写在"核验"列 |
| 待核 | 需要外部核对（书不在手边、或需要跑一次） |

## 审读方式

只对着表核，不读上下文。每条只需回答：这个断言成立吗？依据是哪一种？

发现 ✗ 时，先改正文，再把该行的状态与修法写回表里。表的用途不是记录功劳，是防止同一句话在
两处互相矛盾——第 5 章与第 6 章关于 Hask 公理的冲突，就是靠这张表才暴露的。
